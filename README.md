# JFDIAS.PT — Web Portfolio & Digital Agency

Website profissional e portfólio moderno desenvolvido para **jfdias.pt**, com foco em **Python & IA Automation** e **Cibersegurança (Security-First)**.

## 🚀 Funcionalidades
- **Intro Comercial & Branding:** Apresentação profissional e serviços integrados.
- **Seção BIO & Jornada:** Percurso técnico e académico (ISTEC, Tokio School, C-Academy / CNCS).
- **Portfólio & Labs:** Projetos ativos (`vectra8.tech`, `lilimpa.pt`) e simulações de PenTest/Redes.
- **Painel de Gestão (CMS Local):** Modal interativo em JavaScript para gestão dinâmica de novos laboratórios.

## 🛠️ Tecnologias
- HTML5 / JavaScript (ES6+)
- Tailwind CSS (CDN)
- Lucide Icons
- Vercel Deployment Configuration
